# Testing Skill

Select verification by impact:
- isolated code → focused test + typecheck
- API → API tests + auth/authorization paths
- DB → migration/schema/query checks
- shared contract → generation + affected consumers
- security → positive and negative paths
- integration → cross-application workflow
- release/certification → defined gate evidence

Always rerun a failed check after fixing it.
