# Quality & System Certification Reference

The project uses quality gates and system integration/certification gates established during planning.

Quality gates:
QG-01, QG-02, QG-03, QG-04, QG-05, QG-06.

System certification gates:
SIG-01 System Architecture Review
SIG-02 Cross-Application Workflow Certification
SIG-03 Realtime & Event Certification
SIG-04 End-to-End System Certification
SIG-05 Security & Reliability Certification
SIG-06 Final System Certification

Integration/security/reliability areas include:
SI-02 Cross-Application Identity & Access
SI-03 Shared Data & API Contract Verification
SI-04 Parent ↔ Reception Integration
SI-05 Reception ↔ Library Integration
SI-06 Parent ↔ Shared Leave State Integration
SI-08 Notifications & Escalation Integration
SI-09 Audit & Observability Integration
SI-10 End-to-End Leave Workflow
SI-11 End-to-End Library Workflow
SI-12 Failure / Recovery / Offline Scenarios
SI-13 Security & Isolation Testing
SI-14 Performance & Reliability Testing
SI-15 Production Environment Integration
SI-16 Full System QA & UAT
SI-17 Production Readiness

A gate is not complete merely because code compiles. Its defined acceptance evidence must pass.
