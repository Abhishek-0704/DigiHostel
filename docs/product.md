# DigiHostel Product Reference

## MVP purpose
The SDD defines the MVP around two operational problems:
1. secure parent leave approval;
2. digital late-night library pass management.

Core objectives include reducing impersonation, digitizing library receipts, realtime reception/library dashboards, comprehensive audit trails, offline recovery, and future scalability.

## Roles
- Student
- Parent
- Guardian
- Reception Warden
- Library In-charge
- Hostel Administrator
- Super Administrator

## MVP modules
- Parent Authentication
- Parent Leave Approval
- Digital Library Pass

## Future scope
The SDD lists complaint management, room swapping, emergency alerts, KIIMS integration, notices/community features, official SAP/API integration, and additional hostel modules as future scope.
