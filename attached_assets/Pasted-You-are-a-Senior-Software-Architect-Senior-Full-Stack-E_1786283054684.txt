====================================================
PROJECT CONTEXT
====================================================

This project is a next-generation Hostel Management System being developed for KIIT (Kalinga Institute of Industrial Technology).

The system aims to digitize and improve hostel operations while maintaining enterprise-grade security, scalability, and user experience.

Current KIIT systems include:

• Fretbox (Hostel Management)

• KIIT SAP Portal (Leave Management)

For the MVP, leave data will be obtained through web scraping of the KIIT SAP Portal because official APIs are unavailable.

The system architecture MUST remain modular so that the scraper can later be replaced with official APIs or direct database integrations without affecting other modules.

This project is intended to be scalable enough to support multiple institutions in the future.
